# Data sources

Every external data source used by the project. **Free sources only.**

| Source | What it provides | Access (key? library?) | Rate limits / terms | Module |
|---|---|---|---|---|
| Yahoo Finance chart API (`query1.finance.yahoo.com/v8/finance/chart`) | Daily OHLCV + adjusted close for listed stocks (e.g. `JET2.L`); with `events=div,split`, dividends (per share, quote currency, by ex-date) and splits (`fetch_corporate_actions`, #133) | No key. Plain HTTP via `requests`; needs a browser-like User-Agent (otherwise 429) | **Unofficial, undocumented endpoint.** Yahoo terms: personal, non-commercial use only — revisit before any commercial use. No published rate limit; keep calls light. LSE history before ~2006 is padded filler (see `check_prices`). Close can sit outside high/low on older LSE bars | `solaraalpha.data.prices` |
| Yahoo Finance fundamentals-timeseries API (`query2.finance.yahoo.com/ws/fundamentals-timeseries/v1/finance/timeseries`) | Fiscal-year statements (revenue, EBITDA, net income, EPS, FCF, debt, cash, equity, shares), TTM EPS / share count per reporting period, dated trailing P/E, forward P/E and market cap | No key, no cookie/crumb. Plain HTTP via `requests` with a browser-like User-Agent | **Unofficial, undocumented endpoint**; same Yahoo terms (personal, non-commercial). ~4 fiscal years of statements; market ratios sampled only a few times a year. Dates are period ends, not publication dates (see ADR 0005). `quoteSummary` (estimates, earnings dates) needs a crumb and was rate-limited, so not used | `solaraalpha.data.fundamentals` |
| Yahoo Finance chart API — futures contracts and FX (`HOM27.NYM`, `GBPUSD=X`, `GBPEUR=X`) | Last settle of each NYMEX heating-oil contract month (jet-fuel proxy for the Jet2 model); daily GBP/USD and GBP/EUR | Same endpoint and access as stock prices: one ticker per contract month (root + month code + yy + `.NYM`) | Same Yahoo terms (personal, non-commercial). Delayed settles; expired / far months return nothing and are skipped. No jet-fuel contract on Yahoo, so jet = heating oil × 330 gal/t + a premium fixed from a dated CIF NWE quote (ADR 0009) | `solaraalpha.data.futures`, `scripts/jet2_value.py` |
| Yahoo Finance chart API — indices, ETFs, peer stocks, FX as comparisons (`^FTAS`, `EXV9.DE`, `EZJ.L`, `EURGBP=X`; per stock in `config/benchmarks.toml`; `Rules.benchmark` for the equity curve and the market regime: `^FTAI` = FTSE AIM All-Share since #210, history from 2021 on Yahoo; RS market default still `^FTAS`) | Weekly total-return series to compare a stock against (market, industry, peers), converted to the stock's currency; the book's benchmark; the daily market regime (#142: drawdown, 1-day z, realised vol). **No free UK implied-volatility series**: VFTSE is not on Yahoo and `^VIX` is US, so the regime uses realised volatility only | Same endpoint and access as stock prices | Same Yahoo terms (personal, non-commercial). Indices are price-only (no dividends) and have zero/missing volume; FTSE sector indices (`*.FGI`) have no history, so sector ETFs stand in (ADR 0011) | `solaraalpha.analysis.relative_strength` |
| FCA National Storage Mechanism (`api.data.fca.org.uk/search?index=nsm-search`; documents under `data.fca.org.uk/artefacts/`) | Every regulated UK announcement (RNS etc.) for an issuer, by LEI: publication time, type code, category, headline, full text | No key. JSON POST (the search backend of the NSM website) | NSM terms: material may be used "for any lawful purpose" (no FCA name/logo use). **Search endpoint is undocumented** and may change. Index caps from+size at 10,000 | `solaraalpha.data.announcements` (`search_issuers` / `lei_by_name`: company name → LEI, the filer whose name matches; `scripts/issuers.py`, `scripts/research_universe.py`, and `resolve_issuer` for a research-universe stock with no LEI on file) |
| FCA Official List (`marketsecurities.fca.org.uk/downloadOfficiallist/live`; the page redirects in script to a CSV on `ukla.file.force.com`) — #290 | Every security admitted to the Official List (company, country, listing category, trading venue, ISINs). AIM shares are not on it, so Trading212's London GBX share lines minus these ISINs give the AIM research universe (`scripts/research_universe.py` → `config/research_universe.toml`) | No key. Public download on the FCA's Official List page | **Terms for automated use not stated — flagged**; one download per hand-run refresh, never in CI. Today's list only (no history). The universe built from it also needs the Trading212 instruments call (owner's keys) and a Yahoo check per line; it keeps only companies Trading212 offers and that still trade (survivor snapshot, #291) | `solaraalpha.data.official_list`, `scripts/research_universe.py` |
| GLEIF LEI API (`api.gleif.org/api/v1/lei-records`) | ISIN → LEI and legal name; name search (`filter[fulltext]`) to fill `config/issuers.toml` by hand. Many non-UK issuers' ISINs are not linked to their LEI (46 of the research universe, 2026-10-28): those come from the NSM name match | No key | Official LEI registry; data CC0. Fair-use rate limits | `scripts/research_universe.py` |
| London Stock Exchange FTSE constituents page (`londonstockexchange.com/indices/ftse-aim-100-index/constituents/table`) | FTSE AIM 100 constituents (TIDM, issuer name, market cap) — the watchlist universe (FTSE AIM UK 50 until 2026-10-18) | No key; the page is JS-rendered from `api.londonstockexchange.com/api/v1/components/refresh` (POST, 20 rows a page), which `scripts/universe.py` reads | **Undocumented; LSE website terms unclear for automated use — flagged**, so run by hand once a quarter (5 calls, plus one instrument call per new constituent), never in CI or the pipeline: `config/watchlist.toml` is a dated snapshot (2026-10-18) refreshed after each quarterly FTSE review. Current constituents only (survivorship bias for any backtest) | `scripts/universe.py` ; `config/watchlist.toml` |
| London Stock Exchange instrument endpoint (`api.londonstockexchange.com/api/gw/lse/instruments/alldata/<TIDM>`) | TIDM → ISIN, market (AIM / Main Market) for a new constituent; ICB `sectorcode`, read by hand into `config/benchmarks.toml` `sector` (2026-10-17; FTSE AIM 100 additions 2026-10-18, via `scripts/universe.py`) | No key | **Undocumented; LSE website terms unclear for automated use — flagged.** Answers 403 (CloudFront block) from cloud runners since scan run 14 (2026-10-25), so the pipeline no longer calls it (2026-10-28): a stock's LEI comes from `config/issuers.toml`, else `config/research_universe.toml`, else the NSM filer of the same name; bypass with `scripts/events.py --lei`. `scripts/universe.py` makes one call per new constituent, by hand | `solaraalpha.data.announcements` ; `scripts/universe.py` ; `config/benchmarks.toml` |
| Google News RSS (`news.google.com/rss/search`) | Press headlines + links for a query, last N days (max 100) | No key; needs a browser-like User-Agent | **No published terms for the feed — flagged; personal research use only.** Discovery only: headlines unverified, duplicates common. Skip with `--no-news` | `solaraalpha.data.news` |
| Web search via Claude Code `WebSearch` / `WebFetch` (any public page: company sites, regulators, statistics offices, trade press, news) | Fresh information for the `/research` and `/events` agents: catalysts newer than the event pack, confirmed event dates, commercial / policy / macro context | No key; the agent's own tools, run by hand or in Actions (`agents.yml`, #123) | **Public pages only: no paywall bypass, no logins, no scraping at volume.** Every page relied on is cited and logged in the `evidence` table with its publication and retrieval times (ADR 0016); uncorroborated headlines are not scored. **Flag: the owner should confirm acceptable source types (story map §6 Q6)** — default: any public page, cited. Search and fetch quotas are Claude Code's | `.claude/skills/research/SKILL.md`, `.claude/skills/events/SKILL.md` |
| Trading212 public API (`demo.trading212.com/api/v0` practice / `live.trading212.com/api/v0`, beta; `SOLARA_T212_ENV`) — ADR 0030, #234; orders ADR 0031, #244 | The owner's own account: account summary (cash, value), open positions, pending orders, historical orders with fills (price, quantity, time, taxes), dividends, deposits / withdrawals; instrument metadata (Trading212 ticker, ISIN, type) for which watchlist stocks are tradable; and orders (`POST /equity/orders/limit|stop|market`, `DELETE` / `GET /equity/orders/{id}`), sent only by `scripts/execute.py` when `SOLARA_T212_TRADING` names the account | Free with an Invest / Stocks ISA account. API key + secret (HTTP Basic) in `.env` as `SOLARA_T212_KEY` / `SOLARA_T212_SECRET`; on the practice account one key with every permission, `orders:execute` included (ADR 0031; back to a read-only key for every job but execution before live) | Beta, under active development; per-account limits (summary and pending orders 1 req / 5 s, positions 1 req / 1 s, history 20 req / min, instruments 1 req / 50 s, limit / stop orders 1 per 2 s, market orders and cancels 50 / min, `GET /orders/{id}` 1 / s), `x-ratelimit-*` headers; order calls are not idempotent (never retried). Some timestamp formats undocumented. Account data never committed | `solaraalpha.data.trading212`, `solaraalpha.portfolio.reconcile`, `solaraalpha.portfolio.execution`, `scripts/scan.py` (tradable) |
| Telegram Bot API (`api.telegram.org/bot<token>/sendMessage`, `getUpdates`) — ADR 0033 | Not a data source: the desk thread's window. Sends the agents' posts to the owner's chat and reads the owner's replies in that chat back into the `chat` table | Free; a bot token from `@BotFather` and the chat id in `.env` / GitHub secrets as `SOLARA_TELEGRAM_TOKEN` / `SOLARA_TELEGRAM_CHAT` | Free, no paid tier needed; ~30 messages / s per bot, 4096 characters a message (longer posts truncated). Bots cannot read chat history, so the DB holds the thread. Skipped without the keys | `solaraalpha.desk_chat`, `scripts/chat.py` |
