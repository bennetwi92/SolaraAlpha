# Data sources

Every external data source used by the project. **Free sources only.**

| Source | What it provides | Access (key? library?) | Rate limits / terms | Module |
|---|---|---|---|---|
| Yahoo Finance chart API (`query1.finance.yahoo.com/v8/finance/chart`) | Daily OHLCV + adjusted close for listed stocks (e.g. `JET2.L`); with `events=div,split`, dividends (per share, quote currency, by ex-date) and splits (`fetch_corporate_actions`, #133) | No key. Plain HTTP via `requests`; needs a browser-like User-Agent (otherwise 429) | **Unofficial, undocumented endpoint.** Yahoo terms: personal, non-commercial use only — revisit before any commercial use. No published rate limit; keep calls light. LSE history before ~2006 is padded filler (see `check_prices`). Close can sit outside high/low on older LSE bars | `solaraalpha.data.prices` |
| Yahoo Finance fundamentals-timeseries API (`query2.finance.yahoo.com/ws/fundamentals-timeseries/v1/finance/timeseries`) | Fiscal-year statements (revenue, EBITDA, net income, EPS, FCF, debt, cash, equity, shares), TTM EPS / share count per reporting period, dated trailing P/E, forward P/E and market cap | No key, no cookie/crumb. Plain HTTP via `requests` with a browser-like User-Agent | **Unofficial, undocumented endpoint**; same Yahoo terms (personal, non-commercial). ~4 fiscal years of statements; market ratios sampled only a few times a year. Dates are period ends, not publication dates (see ADR 0005). `quoteSummary` (estimates, earnings dates) needs a crumb and was rate-limited, so not used | `solaraalpha.data.fundamentals` |
| Yahoo Finance chart API — futures contracts and FX (`HOM27.NYM`, `GBPUSD=X`, `GBPEUR=X`) | Last settle of each NYMEX heating-oil contract month (jet-fuel proxy for the Jet2 model); daily GBP/USD and GBP/EUR | Same endpoint and access as stock prices: one ticker per contract month (root + month code + yy + `.NYM`) | Same Yahoo terms (personal, non-commercial). Delayed settles; expired / far months return nothing and are skipped. No jet-fuel contract on Yahoo, so jet = heating oil × 330 gal/t + a premium fixed from a dated CIF NWE quote (ADR 0009) | `solaraalpha.data.futures`, `scripts/jet2_value.py` |
| Yahoo Finance chart API — indices, ETFs, peer stocks, FX as comparisons (`^FTAS`, `EXV9.DE`, `EZJ.L`, `EURGBP=X`; per stock in `config/benchmarks.toml`; `Rules.benchmark` for the equity curve and the market regime, default `^FTAS`; `^FTAI` = FTSE AIM All-Share is also served) | Weekly total-return series to compare a stock against (market, industry, peers), converted to the stock's currency; the book's benchmark; the daily market regime (#142: drawdown, 1-day z, realised vol). **No free UK implied-volatility series**: VFTSE is not on Yahoo and `^VIX` is US, so the regime uses realised volatility only | Same endpoint and access as stock prices | Same Yahoo terms (personal, non-commercial). Indices are price-only (no dividends) and have zero/missing volume; FTSE sector indices (`*.FGI`) have no history, so sector ETFs stand in (ADR 0011) | `solaraalpha.analysis.relative_strength` |
| FCA National Storage Mechanism (`api.data.fca.org.uk/search?index=nsm-search`; documents under `data.fca.org.uk/artefacts/`) | Every regulated UK announcement (RNS etc.) for an issuer, by LEI: publication time, type code, category, headline, full text | No key. JSON POST (the search backend of the NSM website) | NSM terms: material may be used "for any lawful purpose" (no FCA name/logo use). **Search endpoint is undocumented** and may change. Index caps from+size at 10,000 | `solaraalpha.data.announcements` |
| GLEIF LEI API (`api.gleif.org/api/v1/lei-records`) | ISIN → LEI and legal name | No key | Official LEI registry; data CC0. Fair-use rate limits | `solaraalpha.data.announcements` |
| London Stock Exchange FTSE constituents page (`londonstockexchange.com/indices/ftse-aim-100-index/constituents/table`) | FTSE AIM 100 constituents (TIDM, issuer name, market cap) — the watchlist universe (FTSE AIM UK 50 until 2026-10-18) | No key; the page is JS-rendered from `api.londonstockexchange.com/api/v1/components/refresh` (POST, 20 rows a page), which `scripts/universe.py` reads | **Undocumented; LSE website terms unclear for automated use — flagged**, so run by hand once a quarter (5 calls, plus one instrument call per new constituent), never in CI or the pipeline: `config/watchlist.toml` is a dated snapshot (2026-10-18) refreshed after each quarterly FTSE review. Current constituents only (survivorship bias for any backtest) | `scripts/universe.py` ; `config/watchlist.toml` |
| London Stock Exchange instrument endpoint (`api.londonstockexchange.com/api/gw/lse/instruments/alldata/<TIDM>`) | TIDM → ISIN, market (AIM / Main Market); ICB `sectorcode`, read by hand into `config/benchmarks.toml` `sector` (2026-10-17; FTSE AIM 100 additions 2026-10-18, via `scripts/universe.py`) | No key | **Undocumented; LSE website terms unclear for automated use — flagged.** One call per run; bypass with `scripts/events.py --lei`. `scripts/universe.py` makes one call per new constituent, by hand | `solaraalpha.data.announcements` ; `scripts/universe.py` ; `config/benchmarks.toml` |
| Google News RSS (`news.google.com/rss/search`) | Press headlines + links for a query, last N days (max 100) | No key; needs a browser-like User-Agent | **No published terms for the feed — flagged; personal research use only.** Discovery only: headlines unverified, duplicates common. Skip with `--no-news` | `solaraalpha.data.news` |
| Web search via Claude Code `WebSearch` / `WebFetch` (any public page: company sites, regulators, statistics offices, trade press, news) | Fresh information for the `/research` and `/events` agents: catalysts newer than the event pack, confirmed event dates, commercial / policy / macro context | No key; the agent's own tools, run by hand or in Actions (`agents.yml`, #123) | **Public pages only: no paywall bypass, no logins, no scraping at volume.** Every page relied on is cited and logged in the `evidence` table with its publication and retrieval times (ADR 0016); uncorroborated headlines are not scored. **Flag: the owner should confirm acceptable source types (story map §6 Q6)** — default: any public page, cited. Search and fetch quotas are Claude Code's | `.claude/skills/research/SKILL.md`, `.claude/skills/events/SKILL.md` |
