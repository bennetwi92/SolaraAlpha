# AI Trading Agent Team

## Specialized Agents

- **ceo-orchestrator**: Autonomous strategic leadership, organizational design, task delegation, priority management, and agent creation
- **task-builder**: Transform requirements into optimized GitHub issues with prompt engineering and task decomposition
- **team-builder**: Design and optimize AI agent configurations through role research and token-efficient architecture
- **skill-builder**: Capture reusable patterns, document best practices, and prevent recurring mistakes
- **strategy-researcher**: Research and analyze novel trading strategies using quantitative, qualitative, and historical approaches
- **strategy-developer**: Implement, test, and validate production-ready trading strategies with comprehensive coverage, realistic backtesting, and risk controls
- **infrastructure-engineer**: Design, build, and optimize scalable infrastructure for trading systems, data pipelines, and deployments
- **latency-hunter**: Performance optimization specialist identifying bottlenecks through complexity analysis, profiling, query optimization, and memory analysis for high-frequency and real-time trading systems
- **quant-alchemist**: Quantitative investment analysis using statistical modeling, machine learning, and high-frequency data analysis for volatility predictions and risk-adjusted metrics
- **scenario-architect**: Forward-looking scenario modeling, stress testing, and tail risk quantification for portfolio resilience across multiple future paths with VaR/CVaR and Monte Carlo simulations
- **historical-pattern-seeker**: Historical market analysis and pattern recognition across 50+ year horizons for identifying sector rotation cycles, regulatory precedents, and structural parallels to prevent recency bias
- **contrarian-heretic**: Challenge consensus, red-team analysis, counter-evidence discovery, premortem failure scenarios, and bias mitigation for investment decisions
- **code-aligner**: Code quality enforcement, complexity analysis, refactoring recommendations, documentation validation, and anti-pattern detection to ensure maintainable production code
- **interface-ethographer**: Usability and accessibility specialist ensuring WCAG compliance, design system consistency, user journey optimization, and responsive design validation for excellent user experience
- **system-cartographer**: Architecture and resilience evaluation, scalability bottleneck identification, Infrastructure as Code design, cost optimization, dependency mapping, and system architecture validation
