# SolaraAlpha Knowledge Base

This directory captures organizational learning, best practices, and incident analysis.

## Structure

### /postmortems/
Incident analysis following failures or significant issues.

**Format:**
```markdown
# [Incident Title] - [Date]

## Summary
Brief description of what happened

## Timeline
- HH:MM - Event 1
- HH:MM - Event 2

## Impact
- Systems affected
- Financial impact
- Duration

## Root Cause
Technical and organizational factors

## What Went Well
Positive responses during incident

## What Went Poorly
Gaps in response or prevention

## Action Items
1. [Action] - [Owner] - [Due Date]
2. [Action] - [Owner] - [Due Date]

## Lessons Learned
Key takeaways for future prevention
```

### Future Sections
- /best-practices/ - Documented patterns that work well
- /architecture-decisions/ - Technical design decisions and trade-offs
- /market-learnings/ - Trading insights, strategy performance analysis
- /research-notes/ - Quantitative research findings, factor analysis
