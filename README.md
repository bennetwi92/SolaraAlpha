# Solara Alpha

Research, analysis and portfolio management code for the Solara Alpha fund. Python only, free data sources only.

## Quick start

```bash
# needs uv: https://docs.astral.sh/uv/
make install      # uv sync + pre-commit hooks
cp .env.example .env
make check        # lint + types + tests
make notebook     # JupyterLab
```

See [`CLAUDE.md`](CLAUDE.md) for project conventions, layout and workflow.
